# Student Grade manager

## Overview

Student Grade Manager is a desktop application developed using **VB.NET and Windows Forms**. It allows users to enter student names and subject marks, display student records in a DataGridView, and calculate academic results.

This project was created to practise Windows Forms development, object-oriented programming, data handling, and basic grade calculations.

## Features

* **Add Student:** Enter a student's name and marks for Maths, Programming, and Computer Hardware.
* **Input Validation:** Check that marks are valid numerical values within the range of 0 to 100.
* **Display Student Records:** View student marks and calculated results in a DataGridView.
* **Calculate Average:** Calculate the average mark for each student.
* **Grade and Status:** Display the grade and status based on the application's grading rules.
* **Delete Student:** Remove a selected student record.
* **Clear Inputs:** Clear the input fields to prepare for another entry.
* **Class Summary:** Display the total number of students and the class average.

## Technologies Used

* VB.NET
* Windows Forms
* Microsoft Visual Studio
* DataGridView
* Object-Oriented Programming (OOP)

## Application Interface

The application includes input fields for the student's name and subject marks, buttons for adding, deleting, and clearing records, and a DataGridView for displaying student results.

## How to Run

1. Clone or download this repository.
2. Open the solution file (`.sln`) in Microsoft Visual Studio.
3. Allow Visual Studio to load the project.
4. Build the solution.
5. Run the application using the Start button or press `F5`.
6. Enter a student's name and marks, then click **Add Student** to display the record.
